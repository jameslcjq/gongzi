# 表清理后的工作流影响

应用已删除多张弃用表，独立版首版只保留仍存在工作表相关流程。旧流程中引用已删除表的部分需要改写或下线。

## 已删除/弃用表

- 局工资表
- 补发工资
- 职称信息表
- 姓名
- 绩效工资过渡表

## 需要改写的流程

| 原流程 | 影响 | 独立版处理 |
|---|---|---|
| 一体化在职 / 更新工资信息 | 原流程查询“局工资表” | 改为你补充的新规则或改查保留表 |
| 工资年报 / 更新信息 | 原流程查询“局工资表” | 改写取数来源，保留年报计算主逻辑 |
| 职称信息表 / 未命名工作流1 | 源表“职称信息表”已删除 | 首版移除 |
| 职称信息表 / 未命名工作流2 | 源表“职称信息表”和“姓名”已删除 | 首版移除 |

## 仍保留的核心流程方向

- 一体化在职：生成工资年报、核对预算人员。
- 预算在职：更新在职信息、更新薪级、增加薪级、计算基础性绩效工资。
- 预算退休：更新退休信息、更新预算养老金和房补。
- 其他人员：新增后更新、核对其他人员。
- 工资年报：生成、更新绩效工资、更新乡镇工作年限。
- 乡镇补贴：按乡镇工作年限分段调整、增加 1 年。
- 绩效工资：更新身份证。
