# 工资系统a启用工作流采集

采集时间：2026-04-30

目标：脱离明道云后，使用 SQLite 复刻工资系统。本文只记录已启用/已发布工作流；关闭、未启用、草稿流程不纳入第一版复刻。

## 总览

- 工作表事件：8 个

- 更新预算在职信息

- 更新预算在职信息-复制-子流程
- 清空上年工资数据

- 人员待遇申领明细的未命名工作流

## 已采集的计算规则

### 预算在职：核对预算人员

- 查询表：预算在职
- 若查到数据：
  - 基础性绩效工资 = 岗位津贴 + 生活补贴
  - 基本工资 = 岗位工资 + 薪级工资
  - 更新预算在职 7 个字段
- 若无数据：
  - 新增预算在职记录，填写 4 个字段

### 预算在职：增加薪级

- 新薪级 = 当前薪级 + 2
- 使用新薪级查询“薪级工资对照”
- 将匹配到的薪级工资回填到预算在职

### 预算在职：更新薪级

- 查询“薪级工资对照”
- 回填预算在职 1 个字段，推断为“薪级工资”

### 预算在职：计算基础性绩效工资

- 节点名显示为“基本工资”
- 明道云摘要显示：岗位工资 + 薪级工资
- 更新预算在职 1 个字段
- 注意：流程名叫“计算基础性绩效工资”，但节点名叫“基本工资”，复刻时需要二次核对目标字段

### 工资年报：更新信息

- 先执行 JavaScript 节点
- 更新工资年报 2 个字段
- 查询“局工资表”
- 函数计算：
  - LEFT(参加工作时间, 4)
  - YEAR(DATENOW()) - 1 - 结果
- 更新工资年报 3 个字段
- 再查询“一体化在职”，更新工资年报 6 个字段
- 后续继续查询“岗位工资对照”等对照表

### 职称信息表：任职年限

- LEFT(任职 时间, 4)
- YEAR(DATENOW()) - 结果
- 更新职称信息表 1 个字段

### 乡镇补贴：调整乡镇补贴

触发：乡镇补贴新增和更新记录。

已看到的分支：

- 乡镇工作年限 0-4
- 乡镇工作年限 5-9
- 乡镇工作年限 10-14
- 乡镇工作年限 15-19
- 乡镇工作年限 20-24
- 乡镇工作年限 25-29
- 乡镇工作年限 30-34
- 乡镇工作年限 35-39
- 乡镇工作年限 >= 40

每个分支更新乡镇补贴 1 个字段。具体金额需要继续进入节点配置或从对照表采集。

年限分支后还有两个“所有数据可进入该分支”的同步分支：

- 查询“一体化在职”，有数据时更新乡镇补贴 2 个字段
- 查询“一体化退休”，有数据时更新乡镇补贴 2 个字段

### 工资年报：生成工资年报

- 按钮触发：生成工资年报
- 先查询并更新“工资年报”
- 有数据：进入后续分支
- 无数据：新增“工资年报”，填写 28 个字段
- 后续分支 1：查询“岗位工资对照”，有数据时更新工资年报 1 个字段
- 后续分支 2：查询“薪级工资对照”，有数据时更新工资年报 1 个字段

### 工资年报：更新绩效工资

- 按钮触发：更新绩效工资
- 查询“绩效工资”，有数据时更新工资年报 1 个字段
- 查询“一体化在职”，有数据时更新工资年报 2 个字段

### 预算退休：更新预算养老金和房补

- 按钮触发：更新预算养老金和房补
- 查询“退休养老金”，有数据时更新预算退休 1 个字段
- 无数据路径也会更新预算退休 1 个字段
- 查询“一体化退休”，有数据时更新预算退休 1 个字段
- 无数据路径也会更新预算退休 1 个字段

## SQLite 复刻建议

工作流不要照搬明道云“画布”，而是拆成后端服务函数和操作日志。

建议表：

```sql
CREATE TABLE workflow_runs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  workflow_key TEXT NOT NULL,
  workflow_name TEXT NOT NULL,
  trigger_type TEXT NOT NULL,
  source_table TEXT,
  source_record_id INTEGER,
  status TEXT NOT NULL,
  message TEXT,
  created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE workflow_run_steps (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  run_id INTEGER NOT NULL,
  step_order INTEGER NOT NULL,
  step_name TEXT NOT NULL,
  step_type TEXT NOT NULL,
  target_table TEXT,
  affected_rows INTEGER DEFAULT 0,
  detail_json TEXT,
  created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (run_id) REFERENCES workflow_runs(id)
);
```

建议后端函数命名：

- `sync_integrated_active_salary()`
- `generate_annual_salary_report()`
- `verify_budget_active_employee()`
- `on_budget_active_created()`
- `update_salary_grade()`
- `increase_salary_grade()`
- `calculate_budget_active_base_salary()`
- `on_budget_retired_created()`
- `update_retired_pension_and_housing_subsidy()`
- `verify_other_people()`
- `update_annual_report_info()`
- `update_annual_report_performance_salary()`
- `update_township_years_for_annual_report()`
- `on_township_allowance_changed()`
